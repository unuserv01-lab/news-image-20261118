One image that sums up the world's news of Wednesday 18 November 2026: a newspaper front page, THE WORLD TODAY, with 45 verified stories from six continents. Lead: the Gulf war widens as the US strikes Qeshm and Iran hits Bahrain and Kuwait. Second: the Trump–Xi–Putin summit eve in Shenzhen, and Ukraine hitting the Kerch Bridge again. A world map marks the day's six flashpoints, a markets strip carries the Dow's slide and Nvidia's record quarter, and the grid covers world, conflict, diplomacy, tech, and sport — every headline checked against reporting from 17–18 November 2026. The program is a deterministic one-line copy: it writes the image to /output/entry.png, byte for byte identical on every run, with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
